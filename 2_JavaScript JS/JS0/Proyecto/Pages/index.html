    ¿Cómo funciona el cifrado?

    01

    El texto original tiene fragmentos entre paréntesis escritos al revés.

    02

    Para decodificar, se toma cada segmento entre () y se invierte.

    03

    Las partes fuera de paréntesis no se modifican.

    04

    Los paréntesis son removidos; el mensaje resultante es el original.
